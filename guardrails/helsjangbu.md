# 헬스장부 — Guardrail

## 기본 정보

- **정식 브랜드명**: 헬스장부
- **서비스**: PT 트레이너용 운동 리포트 자동 생성 앱 (카카오톡 발송)
- **타겟 고객**: 헬스장 PT 트레이너
- **채널**: 인스타그램 릴스

## 사용 가능한 수치·데이터

- 누적 트레이너 사용자: 337명
- 회원 리포트 열람률: 91%
- 입력 소요 시간: 1분 이내
- 리포트 항목: 운동명, 코칭 포인트, 다음 수업 목표

## 표현 가이드라인

### 반드시 써야 하는 표현
- "헬스장부" (정식 브랜드명)
- 카카오톡 발송 기능 언급 시 "카톡으로 보내진다" 표현 사용 가능

### 절대 쓰면 안 되는 표현
- 재등록률 수치 단정 (예: "재등록률 XX% 상승" — 검증된 수치 없음)
- "자동 생성" 단독 사용 시 맥락 필요 (입력 후 자동 생성되는 구조 설명 포함)

## 특이사항

- 핵심 가치: 트레이너의 전문성 → 회원 신뢰 → 재등록으로 이어지는 흐름
- 대표님 출연 최소화 방향, 직접 카메라 응시 금지
- 앱 화면 녹화 컷 필요 (별도 스마트폰 사용)
