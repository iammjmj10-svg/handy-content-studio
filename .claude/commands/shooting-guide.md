# /shooting-guide

촬영 가이드라인만 단독으로 생성하는 커맨드입니다.
기획안이 이미 확정됐을 때 사용합니다.

---

## 실행 순서

```
Q1. 고객사 이름이 뭔가요?
Q2. 확정된 장면별 기획안을 붙여넣어 주세요.
     (없으면 /content-plan 먼저 실행을 안내합니다)
Q3. 촬영 가능한 공간은 어디인가요?
Q4. 대표님 출연 컷이 있나요? (있음 / 없음)
Q5. 노션 새 페이지로 만들까요, 기존 페이지에 추가할까요?
     → 새 페이지: 상위 페이지 링크 또는 ID
     → 기존 페이지: 해당 페이지 링크
```

Q1 답변 후 → `guardrails/` 폴더에서 해당 고객사 파일을 즉시 확인하세요.

CLAUDE.md의 촬영 가이드라인 규칙을 따라 노션 페이지로 출력합니다.
`examples/shooting-guide/` 폴더에 예시 파일이 있으면 참고합니다.

완료 후:
```
"노션 페이지 생성 완료했습니다. [링크]
레퍼런스 이미지는 각 컷 아래에 직접 삽입해 주세요."
```
