# /content-plan

장면별 기획안 + 촬영 가이드라인을 순서대로 생성하는 커맨드입니다.

---

## 실행 순서

### STEP 1 — 정보 수집

**① 고객사 이름만 먼저 물어보세요.**

```
Q1. 고객사 이름이 뭔가요?
```

Q1 답변 후 즉시:
- `guardrails/` 폴더에서 해당 고객사 파일 확인
- 파일 없으면: "이 고객사 guardrail 파일이 없습니다. 수치·서비스명은 직접 입력해 주세요."

**② 사전질문지 붙여넣기 요청**

```
"사전질문지 내용을 여기에 붙여넣어 주세요."
```

붙여넣으면 아래 정보를 자동으로 파악합니다. 별도로 Q2~Q5를 하나씩 묻지 않아도 됩니다.
- 핵심 기능 / 장점
- 사용 가능한 수치 / 데이터
- 대표님 출연 여부
- 앱 화면 녹화 필요 여부

---

### STEP 1.5 — 레퍼런스 추천 + 대표님 전달 멘트

Q1~Q5 답변이 완료되면, **팀원이 레퍼런스를 직접 고르기 전에** 아래를 수행합니다.

**① 노션 DB 조회**

`collection://3842d4d0-4f34-806c-8161-000b3a78bc95` 에서 브랜드 정보(업종·타겟·목적·차별점)와 가장 잘 맞는 레퍼런스 2~3개를 추천합니다.

각 추천 항목에 선별 이유를 한 줄씩 붙입니다:
```
1. [레퍼런스명] — [노션 페이지 링크]
   선별 이유: [업종 유사성 / 타겟 일치 / 훅 유형 적합성 중 핵심 1~2가지]
```

**② 대표님 전달용 카톡 멘트 생성**

레퍼런스 추천 직후, 노션 DB에서 확인한 형태에 따라 아래 두 가지 중 해당하는 멘트를 출력합니다.

**[링크가 있는 경우]** 복붙 가능한 멘트 출력:
```
안녕하세요 대표님,
[브랜드명]에 걸맞는 레퍼런스 영상 분석하여 송부드립니다!

[레퍼런스 전체적인 톤/특징을 1~2문장으로]

레퍼런스 송부드리오니 한번 봐보시고 의견 부탁드립니다.

1. [링크1]
2. [링크2]
```

**[영상 파일이 첨부된 경우]** 멘트 출력 + 팀원에게 안내:
```
안녕하세요 대표님,
[브랜드명]에 걸맞는 레퍼런스 영상 분석하여 송부드립니다!

[레퍼런스 전체적인 톤/특징을 1~2문장으로]

레퍼런스 송부드리오니 한번 봐보시고 의견 부탁드립니다.

1. [파일명1] (영상 파일 직접 첨부)
2. [파일명2] (영상 파일 직접 첨부)
```
→ 팀원 안내: "노션에서 영상 파일 다운로드 후 카톡으로 직접 전송해 주세요."

멘트 생성 후 팀원에게 확인:
```
"이 레퍼런스 중 선택하시겠어요, 아니면 다른 레퍼런스를 직접 가져오시겠어요?"
```

**③ 레퍼런스 확정 후 추가 질문**
```
"이 레퍼런스, 비슷한 업종 고객사에 전에 쓴 적 있나요?"
→ 있으면: CLAUDE.md 중복 방지 레이어 2 적용 → 훅 유형 자동 전환
→ 없으면: 원래 유형 그대로 진행
```

### STEP 2 — 장면별 기획안 생성

CLAUDE.md의 장면별 기획안 규칙을 따라 HTML 아티팩트 테이블로 출력합니다.
`examples/scene-plan/` 폴더에 예시 파일이 있으면 참고해서 퀄리티를 맞춥니다.

생성 후 반드시 물어보세요:
```
"기획안 확인해보세요. 수정할 부분 있으면 말씀해 주시고,
괜찮으면 이 기획안으로 촬영 가이드라인도 만들까요?"
```

---

### STEP 3 — 촬영 가이드라인 생성

"만들겠다"는 확인을 받은 후 진행합니다.

**먼저 이렇게 물어보세요:**
```
"기획안 보시고 기존에 촬영된 소스가 없는 컷 번호만 알려주세요.
 그 컷만 촬영 가이드 드릴게요.
 (소스 없으면 전체, 소스 다 있으면 편집 순서 가이드만 드릴게요.)"
```

**답변에 따른 분기:**

| 상황 | 처리 |
|---|---|
| 촬영 소스 없음 (전체 신규 촬영) | 전체 컷 촬영 가이드 생성 |
| 소스 있는데 일부 컷 없음 | 팀원이 알려준 컷 번호만 촬영 가이드 생성 |
| 소스 전부 있음 | 편집 순서 가이드만 생성 (촬영 불필요) |
| 촬영 자체 안 함 | STEP 3 전체 건너뜀 |

추가로 물어볼 것:
```
Q8. 촬영 가능한 공간은 어디인가요? (헬스장 / PT룸 / 사무실 / 카페 등)
Q9. 노션 새 페이지로 만들까요, 기존 페이지에 추가할까요?
     → 새 페이지: 상위 페이지 링크 또는 ID 알려주세요
     → 기존 페이지: 해당 페이지 링크 알려주세요
```

CLAUDE.md의 촬영 가이드라인 규칙을 따라 노션 페이지로 출력합니다.
`examples/shooting-guide/` 폴더에 예시 파일이 있으면 참고합니다.

완료 후:
```
"노션 페이지 생성 완료했습니다. [링크]
레퍼런스 이미지는 각 컷 아래에 직접 삽입해 주세요."
```
