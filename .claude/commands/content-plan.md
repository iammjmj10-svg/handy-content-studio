# /content-plan

장면별 기획안 + 촬영 가이드라인을 순서대로 생성하는 커맨드입니다.

---

## 실행 순서

### STEP 1 — 정보 수집

아래 질문을 순서대로 하나씩 물어보세요. 한 번에 다 묻지 말고 답변 받은 후 다음으로 넘어갑니다.

```
Q1. 고객사 이름이 뭔가요?
Q2. 이번 영상에서 보여줄 핵심 기능 또는 장점을 한 줄로 말해주세요.
Q3. 사용할 수 있는 수치나 데이터가 있나요? (없으면 없다고)
Q4. 참고할 벤치마크 릴스가 있나요?
     (1) 링크 붙여넣기
     (2) 유형 선택: 역설공감형 / 에피소드형 / 정보기능형
Q5. 대표님 직접 출연이 있나요? (있음 / 없음)
Q6. 앱 화면 녹화 컷이 필요한가요? (있음 / 없음)
```

Q1 답변 후 → `guardrails/` 폴더에서 해당 고객사 파일을 즉시 확인하세요.
파일이 없으면 "이 고객사 guardrail 파일이 없습니다. 계속 진행할까요?" 라고 물어보세요.

---

### STEP 2 — 장면별 기획안 생성

CLAUDE.md의 장면별 기획안 규칙을 따라 HTML 아티팩트 테이블로 출력합니다.
`examples/scene-plan/` 폴더에 예시 파일이 있으면 참고해서 퀄리티를 맞춥니다.

생성 후 반드시 물어보세요:
```
"기획안 확인해보세요. 수정할 부분 있으면 말씀해 주시고,
괜찮으면 이 기획안으로 촬영 가이드라인도 만들까요?"
```

---

### STEP 3 — 촬영 가이드라인 생성

"만들겠다"는 확인을 받은 후 진행합니다.

추가로 물어볼 것:
```
Q7. 촬영 가능한 공간은 어디인가요? (헬스장 / PT룸 / 사무실 / 카페 등)
Q8. 노션 새 페이지로 만들까요, 기존 페이지에 추가할까요?
     → 새 페이지: 상위 페이지 링크 또는 ID 알려주세요
     → 기존 페이지: 해당 페이지 링크 알려주세요
```

CLAUDE.md의 촬영 가이드라인 규칙을 따라 노션 페이지로 출력합니다.
`examples/shooting-guide/` 폴더에 예시 파일이 있으면 참고합니다.

완료 후:
```
"노션 페이지 생성 완료했습니다. [링크]
레퍼런스 이미지는 각 컷 아래에 직접 삽입해 주세요."
```

---

## 중단 옵션

- STEP 2 후 "기획안만 필요해요" → STEP 3 건너뜀
- 언제든 "처음부터 다시" → STEP 1로 돌아감
