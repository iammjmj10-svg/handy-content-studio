# /scene-plan

장면별 기획안만 단독으로 생성하는 커맨드입니다.
기획안이 이미 있고 수정만 할 때, 또는 기획안만 필요할 때 사용합니다.

---

## 실행 순서

아래 질문을 순서대로 하나씩 물어보세요.

```
Q1. 고객사 이름이 뭔가요?
Q2. 이번 영상에서 보여줄 핵심 기능 또는 장점을 한 줄로 말해주세요.
Q3. 사용할 수 있는 수치나 데이터가 있나요?
Q4. 참고할 벤치마크 릴스가 있나요?
     (1) 링크 붙여넣기
     (2) 유형 선택: 역설공감형 / 에피소드형 / 정보기능형
Q5. 대표님 직접 출연이 있나요? (있음 / 없음)
Q6. 앱 화면 녹화 컷이 필요한가요? (있음 / 없음)
```

Q1 답변 후 → `guardrails/` 폴더에서 해당 고객사 파일을 즉시 확인하세요.

CLAUDE.md의 장면별 기획안 규칙을 따라 HTML 아티팩트 테이블로 출력합니다.
`examples/scene-plan/` 폴더에 예시 파일이 있으면 참고합니다.
