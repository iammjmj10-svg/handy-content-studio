# [헬스장부] 콘텐츠 2 장면별 기획안 예시

> 벤치마크 유형: 에피소드형 (슈링크 스타일)
> 대표님 출연: 없음 (트레이너 캐릭터 설정)
> 앱 화면 녹화: 있음

## 구조 패턴

훅(결과 먼저) → 캐릭터 소개 → 문제 상황 → 제품 발견 → 사용 과정 → 회원 반응 → 수치 증거 → CTA

## 장면 / 자막 테이블

| 장면 | 자막 |
|------|------|
| 헬스장부 리포트 화면 클로즈업 | 실화인가요? |
| 재등록 카톡 알림 화면 | 이거 하나 이용했더니 헬스장 재등록 연락이 미친듯이 옵니다 |
| 트레이너분이 운동하고 있는 영상 + 관련 사진 2개 첨부 **[대표님 출연]** | 이분은 민준 트레이너님 |
| 텅 빈 PT 수업 예약 캘린더 화면 | 3개월째 재등록이 안 나와서 고민이었어요 |
| PT 수업 마무리 후 트레이너 혼자 남은 모습 **[대표님 출연]** | 실력도 있고 성격도 좋은데 |
| 트레이너가 스마트폰 보다가 내려놓는 모습 **[대표님 출연]** | 수업 끝나면 회원한테 아무것도 못 보내고 있었거든요 |
| 헬스장부 앱 아이콘 or 메인 화면 | 그래서 그가 바로 사용한 것 |
| 앱 사용자 수 화면 or 대시보드 화면 | 337명 트레이너가 검증한 헬스장부입니다 |
| 앱에 운동 내용 입력하는 손 클로즈업 **[대표님 출연]** | 입력하는 데 1분도 안 걸려요 |
| 오늘 수업 내용 입력 화면 | 그냥 오늘 뭐 했는지 적으면 |
| 완성된 리포트 화면 스크롤 | 운동 기록, 코칭 포인트, 다음 목표까지 |
| 카톡 발송 완료 화면 | 리포트로 정리돼서 카톡으로 보내져요 |
| 회원이 카톡 열어보는 모습 **[대표님 출연]** | 그러니까 회원 입장에선 수업 끝나도 관리받고 있다는 느낌이 들고 |
| 재등록 카톡 메시지 화면 클로즈업 | 결국 재등록으로 이어지는 거죠 |
| 재등록 알림 여러 개 쌓인 화면 | 그랬더니 회원들 재등록 연락이 빗발쳤어요 |
| 헬스장부 앱 메인 화면 | 337명 트레이너분들의 재등록률을 바꿔준 헬스장부 |
| 요금제 or 가격 화면 클로즈업 | 하루 597원으로 지금 바로 시작해보세요 |

## 핵심 포인트

- 빨간색(대표님 출연) 장면: 트레이너 캐릭터를 연기하는 방식 → 직접 응시 금지, 자연스러운 상황 연출
- 앱 화면 녹화 컷은 별도 스마트폰으로 진행
- 수치 "337명", "하루 597원" 정확히 사용
