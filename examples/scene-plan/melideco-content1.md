# [멜리데코 드멜리 라부애] 장면별 기획안 예시

> 벤치마크 유형: 에피소드형 (실제 사용자 스토리)
> 대표님 출연: 있음 (슬기님 캐릭터)
> 채널: 인스타그램 릴스 (세로 방향, 상반신 기반)

## 구조 패턴

훅(결과) → 캐릭터 소개 → 문제 상황 → 제품 발견 → 기능 설명(차별점) → 결과 확인 → CTA

## 장면 / 나레이션 테이블

> 빨간색 글씨 장면: 따로 촬영 필요
> 전체적으로 릴스 비율에 맞춰 세로 방향, 상반신 기반으로 촬영

| 장면 | 나레이션 |
|------|----------|
| (없음) | 와.. 실화인가요? |
| 싱크대 지저분한 모습 / 깨끗한 싱크대 모습 (교차 컷) | 싱크대가 이렇게 바뀌었습니다. |
| 화살표로 대표님 가리키며 '슬기'라고 표시 **[대표님 출연]** | 이 분은 슬기님. |
| 대표님께서 부엌에서 요리하시는 모습 **[대표님 출연]** | 요리는 좋아하는데 |
| 싱크대 바라보며 한숨쉬는 영상 **[대표님 출연]** | 싱크대 위만 보면 한숨이 나오셨대요. |
| 물때로 가득한 이전 와이어 거치대 영상 혹은 사진 | 와이어 거치대는 물때로 가득하고, |
| 세제통 누를 때마다 쓰러지는 영상 | 세제통은 펌핑할 때마다 쓰러져서 |
| 싱크대쪽이 물로 적셔져있는걸 보며 황당해하는 모습 **[대표님 출연]** | 고민이 많았다고 하시더라고요. |
| 빈 부엌에 손가락 튕기는 모습 → 라부애 등장 → 다시 손가락 튕기는 모습 **[대표님 출연]** | 그래서 슬기님이 설치한 것. 바로 드멜리가 직접 설계한 싱크 캐디 라부애입니다. |
| 다른 각도로 라부애 확대한 모습 | 이게 기존 거치대랑 뭐가 다르냐면요. |
| 가까이서 촬영한 샷 | 나사 하나까지 전부 STS304 스테인리스 스틸이라 |
| 녹 슬지 않고 깨끗하다는걸 보여주는 샷 | 녹슬 걱정도 없고, |
| 겉 부분(화이트 레이어) 가리키는 모습 | 표면엔 매트 화이트 레이어를 입혀서 |
| 물때, 설거지 없이 설거지하는 모습 | 물때랑 스크래치도 알아서 방어해줘요. |
| 세제 펌핑해도 안흔들리는 모습 | 와이어 대신 평평한 플랫 패널 구조라 이물질이 낄 틈 자체가 없고요, |
| 볼트 가리키는 모습 | 이렇게 볼트로 단단히 고정돼 있어서 |
| 라부애 초근접샷 | 세게 펌핑해도 흔들림이 없습니다. |
| 세제 3개를 놓는 모습 | 심지어 28cm 넓은 공간에 세제통 세 개를 나란히 놔도 여유롭고, |
| 행거에 수세미 걸어놓는 모습 | 앞쪽 행거에 수세미를 걸어두면 빠르게 건조되고, |
| 물이 흘러 내려가는 모습 | 물은 V자 경사를 따라 싱크대로 곧장 흘러 내려가요. |
| 3단 분리되는 영상 | 청소할 땐 3단으로 분리해서 |
| 3단 분리된걸 설거지하는 영상 | 흐르는 물에 슥 닦아내기만 하면? |
| 물기 하나 없는, 깔끔한 라부애 근접샷 | 끝입니다. |
| 깔끔한 싱크대 왼쪽에서 오른쪽으로 촬영한 영상 | 봐봐요, 슬기님 싱크대 완전히 달라졌죠? |
| 라부애 설치하는 모습 | 싱크 캐디 라부애, 지금 바로 최저가 링크 만나보세요! |

- B급 연출 금지
- 대표님 직접 응시 최소화 → 자연스러운 부엌 상황 연출
- 세로 방향, 상반신 기반 촬영
