# [펫타임즈] 찹찹식기 촬영 가이드라인 예시

> 노션 원본: https://app.notion.com/p/3a02d4d04f3480029c45cdd3e41f2292
> 고객사: 펫타임즈
> 상품: 찹찹식기 (호환성/흡착력 강조)
> 구조 유형: 임팩트 훅 → 원리 설명 → 호환성 → 세척 편의성 → CTA

---

## 1️⃣ 준비물 / 콘셉트

**콘셉트:** "엥? 엥? 엥? → 진짜 안 떨어져요!!!!" 임팩트 훅으로 시작하는 흡착력 강조 릴스

**준비물:**
- 찹찹식기 완제품 (윗식기+밑식기 세트, 컬러 다양하게)
- 호환 시연용 다양한 그릇 (세라믹, 유리 수반, 스테인리스, 츄르 접시 등)
- 아기 흡착 식판 (비교용)
- 출연 가능한 고양이
- 오버레이용: "🔒 특허 출원 준비 중" 뱃지, 기존 발행 릴스 댓글 스크롤 캡처본
- 하단 고정 안내 자막: *"바닥이 평평하고 흡착판보다 넓은 식기에 한해 호환됩니다"*

---

## 2️⃣ 컷별 촬영 가이드

**전체 흐름:** 훅(안 떨어져요) → 제품 소개 → 흡착 원리 → 호환성 시연 → 세척 → CTA

| 컷 | 가이드 |
|----|--------|
| **1. [안 떨어져요..] 화면** | 양손으로 스테인리스+밑식기, 유리그릇+밑식기를 드는 모습 |
| **2. [진짜 안 떨어져요!!!!] 화면** | 양손으로 유리그릇+밑식기와 세라믹+밑식기를 든 채 흔들기 |
| **3. [영상 올리자마자 댓글 폭발한 저희 찹찹식기,] 화면** | 찹찹식기 완제품(세트) 정면 컷 |
| **4. [어떻게 안 떨어지는지 궁금하시죠?] 화면** | 기존 윗식기와 밑식기를 들어올렸을 때 둘이 안떨어지는 모습 |
| **5. [아기 식판 있잖아요? 그릇 뒤집힐까 봐 붙어있는 흡착판!] 화면** | 흡착 테스트 영상 (있을 경우) |
| **6. [바닥이 평평한 그릇이면] 화면** | 세라믹·유리·스테인리스·츄르 접시 등 다양한 그릇 나란히 놓은 컷 |
| **7. [밑식기 바닥의 실리콘 흡착판이] 화면** | 밑식기 뒤집어서 실리콘 흡착판 부분 가리키는 모습 |
| **8. [평평한 바닥에 착 붙어요.] 화면** | 밑식기를 테이블에 얹는 순간 ("착" 소리 강조) |
| **9. [윗식기만 쏙 분리돼서] 화면** | 윗식기가 밑식기에서 분리되는 순간 (슬로우모션 추천) |
| **10. [설거지도 쉽게 할 수 있고요!] 화면** | 분리된 윗식기를 물로 씻는 손동작 클로즈업 |
| **11. [출시 전부터 반응 폭발적인 찹찹식기 궁금하시다면 댓글 남겨주세요] 화면** | 찹찹식기 완제품 정면 (대각선 위에서) |
| **12. [예약 링크 바로 보내드릴게요!] 화면** | 다양한 컬러 세트 나란히 + 손가락으로 가리키는 마무리 컷 |
